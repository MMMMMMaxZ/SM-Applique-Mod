# Max's Logo Lab

> A powerful custom decal tool & gadget collection mod for Scrap Mechanic.
>
> 一套集自定义贴花工具与趣味部件于一体的《废品机械师》功能模组。

---

## 📦 Overview / 概述

**Max's Test Mod** is a experimental mod that brings a fully functional **custom decal device** into the game, along with a variety of test gadgets for fun and demonstration purposes.

**Max's 测试模组** 是一个实验性模组，为游戏带来了一套功能完整的 **自定义贴花装置**，同时附带多种测试用趣味部件。

---

## 🎨 Core Feature / 核心功能

### Custom Decal Device – Unlimited Possibilities!

- Use built-in patterns and motifs out of the box
- Create your own icons from basic shapes (circles, rectangles, lines, etc.)
- Save your custom icons and recall them anytime
- No coding or external tools required – all done in-game!

### 自定义贴花装置 – 无限可能！

- 开箱即用，内置多种图案与花纹
- 通过基础图形（圆形、矩形、线条等）自由组合创作
- 支持保存自定义图标，随时调用
- 无需编程或外部工具 – 全在游戏内完成！

---

## 🔗 Share & Sync / 分享与同步

- Export your custom decals as **blueprints**
- Share blueprints with other players
- Import others' blueprints via the device and save their icons to your own library

- 支持将自定义贴花导出为 **蓝图**
- 可与其他玩家分享蓝图
- 通过装置加载他人蓝图，即可将图标保存到自己的库中
